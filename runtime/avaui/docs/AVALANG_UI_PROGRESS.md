# avalang.ui.dll — Progreso de Implementación

Checklist de las fases definidas en `docs/AVALANG_UI_IMPLEMENTATION_PLAN.md`.
Este documento es el equivalente de `docs/PAL_PROGRESS.md` pero para el
módulo `ui/` (avalang.ui.dll), y arranca solo porque el PAL de
`avalang.dll` ya está estable para Windows (ver Fase 6 de
`docs/Platform_Foundation.md`).

## Alcance actual: solo Windows

Misma decisión de alcance que en `avalang.dll`: mientras dure esta
etapa, el trabajo activo de `avalang.ui.dll` se enfoca exclusivamente
en el backend Windows. Los backends de Linux (`ui/src/platform/linux/`)
y macOS (`ui/src/platform/macos/`) quedan **en estudio**: existen como
STUB (compilan, no implementan nada), pausados a propósito y sin
recibir trabajo nuevo hasta que se decida retomarlos. Ninguna fase de
abajo se considera bloqueada por ellos — "completa" en este documento
significa "completa para Windows".

Leyenda: ✅ completa (Windows) · 🔄 parcial / en progreso · ⬜ no iniciada · 📚 en estudio (pausado)

## A partir de la Fase 20: Architecture Freeze

`AVAUI_ARCHITECTURE_FREEZE_PLAN.md` (mismo folder) rige el trabajo a
partir de acá: no más módulos/interfaces/abstracciones nuevas, foco en
completar lo que ya existe, validar, documentar y testear. La Fase
20.0 (fila 20 abajo) es el primer trabajo hecho bajo ese plan.
